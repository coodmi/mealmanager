## 📱 Test It Now (3 Steps)

### Step 1: Run the App
```bash
flutter pub get
flutter run
```

### Step 2: Register
1. Click **"Register"** tab
2. Fill in the form:
   - Name: Your Name
   - Mobile: 01712345678
   - Email: your@email.com
   - Password: test123
3. Click **"Sign Up"**

### Step 3: Check Console & Enter OTP
1. Look at your terminal/console
2. Find the OTP code (6 digits)
3. Also check the green SnackBar at bottom
4. Enter the OTP in the verification screen
5. Click **"Verify"**

**That's it!** ✨
