                      TROUBLESHOOTING

═══════════════════════════════════════════════════════════════════

Account Already Exists?
→ Delete from Firebase Console first

Can't Login?
→ Check Firestore has user document with 'role' field

Need Different Email?
→ Modify testAccounts map in test_account_creator.dart

Need to Reset?
→ Delete user in Firebase Auth + user doc in Firestore
